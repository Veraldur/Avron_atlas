# Windows EXE из исходников

Готовая Windows x64 программа поставляется отдельно. Для самостоятельной пересборки после изменений в HTML/JS/ассетах установите Python 3 и Go 1.23+, затем из корня проекта запустите:

```shell
python launcher-source/rebuild_exe.py
```

Скрипт временно копирует файлы в `launcher-source/static`, собирает Windows x64 GUI `.exe` и удаляет временную папку. Для конечного пользователя Python и Go не нужны.
