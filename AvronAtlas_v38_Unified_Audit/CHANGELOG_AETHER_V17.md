# AvronAtlas v17 — Canvas Keyframes

- На холсте режиссёра выбор слоя, свободное перемещение мышью, изменение размера за маркер.
- Геометрия x/y/w/h сохраняется **в текущем ключевом кадре**, не меняя исходную композицию Pop-up.
- Воспроизведение интерполирует позицию и размер между кадрами.
- JSON v17 — копия содержимого v16 с обновлённой меткой совместимости, без изменения авторского контента.

Ограничения: старый Пантеон и карта остаются самостоятельными движками; интеграционный браузерный тест не выполнен.
