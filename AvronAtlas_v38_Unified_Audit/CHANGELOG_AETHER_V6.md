# AvronAtlas Aether Studio VI — системная навигация

- Новый входной экран (портал мира), карта больше не является стартовым экраном интерфейса.
- Единая быстрая навигация: Главная, Карта, Статьи, Летописи, Витрины, JSON.
- Витрины перечислены на главной, доступны повторно по идентификатору.
- Явная кнопка «Сохранить JSON мира» внутри конструктора витрин; скачивает полный мир.
- Автосохранение оставлено, но зависит от лимитов localStorage браузера; JSON — основной надёжный способ хранения.
- Декоративная архитектурная оболочка главного меню с адаптивной сеткой.
- Существующие экраны/механики сохранены без полной замены движка карт.

## Ограничения
- Реальное тестирование всех путей в браузере не завершено.
- Статьи и витрины пока работают с общей моделью world, а не с серверной БД.
- Галерея Пантеона по-прежнему использует собственный внутренний движок.
