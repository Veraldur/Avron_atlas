# AvronAtlas v32 — запуск

Распакуйте ZIP целиком и запустите `START_OFFLINE_WINDOWS.bat` (требуется Python) или при наличии `.exe` запускайте Windows-сборку напрямую. Скрипты, изображения, JSON Аврона и Phaser находятся локально. Выберите мир «Аврон» в меню. Если осталось автосохранение версии v31, экспортируйте его до замены. Для перехода к демонстрации: Исследование городов → Амена → Гильдейские улицы → Мастерская камнерезов.

Верхняя панель содержит «Реликварий». В режиме Редактора в нём можно создавать артефакты и загадки, а в Амене — менять точки на иллюстрации. Кнопка «Сохранить JSON» выгружает авторский мир. Личный прогресс читателя в него не включён.

Ограничения и список проверок см. в QA_REPORT_V32.md. Версия использует текущий Phaser, без внедрения React и без серверной синхронизации.
