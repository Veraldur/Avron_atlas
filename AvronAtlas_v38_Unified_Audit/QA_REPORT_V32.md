- JS-синтаксис всех файлов `src/`, `pantheon/` (Node `--check`).
- Проверка JSON и полного совпадения с `default-world-v32.js`.
- Проверка сохранения всех 266 исходных объектов и трёх комнат из v31.
- Граф ссылок `AvronNav.audit()`: существование целевых ID, проверка узлов и коллекций, ссылки нового типа `relic`, `puzzle`, точки на картинке.
- Изолированный Chromium: открытие всех трёх артефактов, добавление в Реликварий, решение загадки, переход к наградной статье, создание и изменение нового артефакта.

## Не подтверждено полным прогоном

- Живой полный интерфейс Phaser с картой Аврона и всеми старыми конструкторами.
- Загрузка изображений в Chromium-тесте: тестовые страницы имеют временное содержимое без доступа к assets, так как переход к localhost/file URL блокируется системой.
- Windows EXE на настоящем ПК (дополнительная сборка — кросс-компиляция).
- Совместимость всех старых сторонних скриптов с необычными JSON пользователя при долгой работе и после тысяч переходов.

## Особенности редактора

- В `relics[]` находятся авторские данные предмета, в `puzzles[]` — логика загадки и ID наградной статьи.
- `explorerNodes[].links` и `contentLinks` ссылаются на эти ID.
- Изменения предметов/загадок сохраняются через `scheduleSave()` и экспорт JSON; библиотека читателя отдельна.
- При удалении артефакта скрипт удаляет исходящие и входящие ссылки навигации, но не автоматически переписывает текстовые упоминания в статьях и не удаляет загадки, использующие предмет. `AvronNav.audit()` показывает такую зависимость как ошибку — автору нужно исправить её вручную.
