# AvronAtlas — Aether III

## Изменения
- Карта: боковые панели можно скрывать отдельными золотыми боковыми ручками; справа стартует свёрнутой на большом экране.
- Компактный плавающий HUD оставлен основным набором инструментов. Оформление панели стало более контрастным и полупрозрачным.
- Фон пространства карты: три варианта (синева, туман, пергамент), выбор сохраняется в localStorage.
- Навигация: дополнительное меню для переходов на маленьком экране, а также переключателя фона.
- Библиотека объектов карты: реальные типы вместо длинного плоского списка; категории отсортированы, группа раскрывается по требованию, большие группы подгружаются порциями.
- Витрины: отдельное создание редактируемой копии шаблона Пантеона без изменения канонической коллекции; исходный Пантеон продолжает работать отдельно.
- Витрины: выбор локального изображения с немедленным предпросмотром, индивидуальные изображения витрины (без перезаписи арта оригинального объекта); создание или открытие статьи непосредственно из экспоната.
- Атлас связей: отметка «Требуется предыдущая связь» с отдельным выбором статьи-предпосылки; без настройки ограничения записи изначально доступны.
- Оповещение «Новое знание открыто» при отметке статьи прочитанной и разблокировке зависимостей.

## Границы реализации
- Прогресс прочтения по-прежнему общий для локального JSON, а не по отдельным пользователям.
- Пантеон ещё использует собственный движок; новый шаблон создаёт отдельную витрину на базе данных Пантеона.
- Полный визуальный браузерный прогон и e2e-тестирование не выполнены. Изменения проверены синтаксически.
- Крупные изображения, встраиваемые в JSON, могут заполнить localStorage: рекомендован размер до 7 МБ, резервное сохранение JSON.
