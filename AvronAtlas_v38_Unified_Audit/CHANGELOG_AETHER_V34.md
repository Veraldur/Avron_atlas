# AvronAtlas v34 — Мастерская сюжетов

## Вместо двух предсказуемых шаблонов

- Оригинальный комбинаторный офлайн-генератор: 24 нестандартные ситуации, по 12–16 механизмов конфликтов, зацепок, поворотов, разных способов действовать и последствий, плюс наборы атмосферных мотивов.
- Размер подборки: 6 / 12 / 24 карточки; кнопка «Ещё» добавляет, не заменяет старые. До 120 карточек за один сеанс. Повторы комбинаций в одном сеансе исключаются.
- 13 направлений: смешанное, события, конфликты, приключения, персонажи, существа, связи, расследования, политика фракций, артефакты, сцены, развязки, слухи.
- 9 атмосфер: любая, загадка, политика, сон, чудо, страх, драма, ирония, эпос. Три степени творческой свободы.
- «☆» сохраняет понравившиеся карточки, «↻ Другой вариант» пересобирает только одну, «Вставить черновик» добавляет предложение в текущую статью. Черновик не утверждается каноном.
- Близкое окружение Аврона остаётся связанным с оригинальными ID материалов и показывается под карточками. Автоматическая генерация не создаёт фактов в JSON.
- Улучшенный ИИ-запрос через шлюз: структурированные карточки вместо одного текста, количество, атмосфера, пожелание автора, список тем, которые не надо повторять. Модель OpenAI либо Ollama подключается только по явному действию.
- Windows x64 EXE содержит Phaser, браузерный интерфейс и локальный безопасный AI-шлюз: Python не требуется, необходим установленный Edge/Chrome. Не меняет схему мира.

## Как глава DMGuide повлияла на конструкцию

Из пользовательского фрагмента главы 4 взяты общие **принципы**: ситуация вместо предопределённого сюжета; разные зацепки; конфликт целей; действия обитателей; несколько способов решения; нарастание ставок; последствия и развязки. Таблицы с готовыми приключениями и фразы из книги в приложение не копировались — словари фраз оригинальные, написанные для AvronAtlas.

## Ограничения

Локальный генератор — не нейросеть: это авторские сюжетные комбинаторы, а не понимание всего текста мира. В режиме строгого канона идеи всё равно остаются гипотезами. Для настоящей модели необходим API-ключ OpenAI или установленная Ollama. Подключение API может быть платным. Сборка EXE на Windows не запускалась в среде теста; все тесты браузера проведены изолированно, а тест локального шлюза — на Linux с имитацией Ollama.
