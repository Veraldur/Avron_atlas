# AvronAtlas v9 — Interactive Atelier

- Добавлен визуальный Pop-up редактор: перетаскивание блоков, изменение размера через угловой маркер, инспектор текста и изображений.
- Формат существующих `entity.popup.blocks` не меняется; старые карточки совместимы.
- Предпросмотр Pop-up на карте и кнопка завершения доступны в визуальном редакторе.
- Витрины: сортировка экспонатов перетаскиванием мышью, сохранение порядка в `showcase.order`.
- Старые числовые настройки Pop-up, ссылки на статьи и карты оставлены без изменений.

## Ограничения
- Пока нет универсального холста для всех конструкторов: Pop-up получил свой рабочий редактор, использующий общую структуру блоков.
- Проект использует локальное хранение; экспорт JSON нужен для надёжной резервной копии.
- Проверка браузерных пользовательских сценариев ещё необходима. JavaScript проходит `node --check`.
