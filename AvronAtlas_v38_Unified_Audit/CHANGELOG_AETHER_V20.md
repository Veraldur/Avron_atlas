# AvronAtlas v20 — сцены и Летописи

- Исправлен источник демонстрации: мигрированный JSON не содержал сцену «Порог Сна». Создана **демонстрационная реконструкция** из двух локальных артов (оригинальных кадров «Порог Сна» в предоставленном JSON не было).
- Объект «Террасы Белого Прилива» связан с `dream-threshold / dream-opening` и использует Pop-up типа `scene`.
- Scene-Pop-up показывает графический анимированный тизер автоматически вместо текстового холста.
- Кнопка «Перейти / Исследовать» показывает полноценную сцену с управлением, а не пустой экран летописи.
- Режиссёр редактирует кадры именно `chronicleBooks[].scenes[]`: таймкоды, название, описание, арт, эффект; можно добавлять/удалять/переставлять кадры. Те же кадры используются в мини-сцене и полном просмотре.
- JSON мира не копирует исходные записи Пантеона, объектов, статей. Оригинальный JSON v19 сохранён в примерах.

Ограничение: исходная художественная сцена «Порог Сна» в переданном JSON отсутствовала, поэтому кадры демонстрационные. Полный браузерный регрессионный тест не проводился.
