# AvronAtlas v34 · Мастерская сюжетов

## Быстрый старт

1. Откройте Аврон или свой JSON; переключитесь в **Редактор**.
2. Откройте любую **Статью** и нажмите **Советник Летописца**.
3. Выберите направление (по умолчанию «Смешать всё»), атмосферу, творческую свободу, размер подборки и глубину связей.
4. Нажмите **«Набросать 12 идей»**: работает офлайн. **«Ещё 12»** добавит новую подборку, не стирая прежнюю.
5. Оставьте интересные карточки через ☆, перегенерируйте скучную кнопкой ↻. «★ Избранное» оставляет на экране только отмеченные.
6. **«Вставить черновик»** добавляет выбранный текст в текущую статью. Как и раньше, изменения статьи нужно сохранить штатной кнопкой редактора.

## Пример использования

Откройте статью «Утраченное обещание камнерезов», выберите тему «Сновидение» или «Интрига» и радиус связей 2–3. Сюжеты опираются на связанные записи Аврона. Для совершенно новой статьи вручную укажите город или регион.

## Настоящий ИИ — отдельный режим

**Без модели** доступен большой локальный генератор: это не AI. С моделью кнопка **«ИИ: создать подборку»** запрашивает до 12 разных сюжетных карточек, с альтернативными решениями и последствиями. Запрос передаёт только текущую статью (до 4500 символов) и до 14 ближайших материалов (краткие описания). Ключ не попадает в мир или браузер; его читает локальная оболочка из переменных среды. Ответы могут ошибаться и всегда требуют подтверждения.

### OpenAI

В PowerShell, в папке с EXE:

```powershell
$env:AVRON_OPENAI_API_KEY = Read-Host 'Введите API ключ'
$env:AVRON_AI_MODEL = 'gpt-5.5'
& '.\AvronAtlas_v34_Story_Forge_Windows_x64.exe'
```

Для облачной модели требуется интернет и отдельный тариф API. Установленная подписка на ChatGPT не является API-ключом. После закрытия программы сотрите переменную `Remove-Item Env:AVRON_OPENAI_API_KEY`.

### Ollama (после первоначальной установки — офлайн)

Установите Ollama и загрузите подходящую модель, например `ollama pull qwen3:8b`. Запустите Ollama. В PowerShell:

```powershell
$env:AVRON_AI_PROVIDER = 'ollama'
$env:AVRON_AI_MODEL = 'qwen3:8b'
& '.\AvronAtlas_v34_Story_Forge_Windows_x64.exe'
```

Некоторые маленькие модели возвращают меньше карточек, чем запрошено: это отображается в панели. Большие партии могут занимать значительное время.

## Что важно для работы с готовым миром

- Импорт JSON по-прежнему поддерживается. Схема мира в v34 не менялась.
- Результаты до вставки — временная подборка; они не экспортируются в JSON и не правят канон.
- `window.AvronWriterAdvisor.ideas(id, task, mode, {count:12})` остаётся доступным для тестов.
- Ограничение на 120 карточек бережёт производительность браузера при многократной генерации.
- Проект содержит полный исходный JS-движок; Windows-EXE использует установленный Edge или Chrome как окно без внешнего localhost-скрипта.

## Тестирование

Пройден изолированный Chromium-цикл 24 → ещё 24 → избранное → перегенерация → вставка в статью. Исходный Аврон из v33 содержит 266 объектов, они не изменены. Мок-тест локального Ollama-шлюза вернул шесть отдельных идей; чужой Origin отвергнут. **Полный прогон всей страницы с Phaser и запуск Windows EXE не подтверждены**: Chromium этой среды блокирует навигацию на localhost.
