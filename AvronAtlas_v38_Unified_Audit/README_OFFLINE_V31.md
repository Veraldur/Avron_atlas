# AvronAtlas v31 — офлайн-копия

## Быстрый запуск

1. Полностью распаковать ZIP. **Не запускайте `index.html` прямо внутри ZIP.**
2. Windows: выполнить `START_OFFLINE_WINDOWS.bat`. Нужен установленный Python (`py -3` или `python`); проект сам не скачивает пакеты и не подключается к сети. Сервер работает только на `127.0.0.1:8765` и завершается при закрытии окна командной строки.
3. Альтернатива: из папки проекта запустить `python -m http.server 8765 --bind 127.0.0.1`, открыть `http://127.0.0.1:8765`.
4. Открытие `index.html` напрямую в браузере без сервера может частично работать, но некоторые браузеры ограничивают загрузку карт/текстур при `file://` — рекомендуется локальный сервер.

На главном экране доступны **«Аврон»**, **«Новый мир»** и **«Продолжить локальное сохранение»**, если оно уже есть. Замена локального сохранения требует явного подтверждения. JSON мира следует сохранять через «Файлы → Экспорт JSON» — браузерное хранилище может быть очищено, а особенно крупные изображения не всегда в нём помещаются.

## Что исправлено

- Глобальные кнопки **Назад / Вперёд** (клавиши Alt+← / Alt+→) для переходов через `AvronNav`, витрины, комнаты, города, книги и основную панель. Прокликивание нативных старых диалогов остаётся частично вне истории.
- Более понятный редактор места: отдельные поля и ссылки с поиском по материалам, перестановка, удаление, проверка целей до сохранения. Больше не нужно редактировать JSON-массив маршрутов вручную.
- «Создать подземелье» и «Создать сюжетное приключение» — разные действия. Тип хранится в `adventureRooms[].kind`, объект карты не создаётся автоматически.
- При создании новой Летописи `chronicleBooks` автоматически создаётся связанная художественная запись `chronicles` с тем же редактором, что использует Пантеон; `cinematicId` хранит ссылку в JSON. Это не создаёт двойную копию статьи или события.

## Ограничения

История `Назад` покрывает новые стандартные маршруты и большинство переходов в новых движках, но не все существующие обработчики старых модулей. Полная интеграционная проверка Phaser и сотен материалов всё ещё необходима. Никакие серверные аккаунты не реализованы; хранение только локальное.
