# v33 — Советник Летописца

- Новый боковой советник прямо в художественном редакторе статьи (`src/writer-advisor-v33.{js,css}`).
- Контекстные связи из канонического JSON, поиск географических соседей, ручной якорь, радиус 1–3.
- Режимы «Строго по канону / Творческий / Неожиданный»; задания «Событие / Конфликт / Квест / Персонаж / Противник / Связи».
- Офлайн-шаблонные идеи без модели, явное различие между ними и генерацией через ИИ.
- Вставка идеи в статью только по команде пользователя; исходный JSON не меняется при просмотре советов.
- Защищённый локальный Go-шлюз для OpenAI Responses API или Ollama, ключ OpenAI берётся только из окружения процесса.
- Не менялись Phaser, форматы витрин, модули загадок и базовая структура мира.
