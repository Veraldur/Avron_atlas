# AvronAtlas Aether · визуал и исправления v2

## Сделано
- В Атласе связей кнопка «Показать ещё» сохраняет позицию общего скролла и внутреннего списка.
- Категории Атласа связей автоматически формируются по реальным типам объектов мира: Подземелье, Портал, Город, Страна и т. д. Объекты не дублируются.
- Группы объектов Атласа связей можно сворачивать по типам.
- У статей есть статус «Прочитана»; записи пересечений могут скрываться в Просмотре до прочтения связанной статьи.
- Обычные связи карты теперь можно скрывать от Просмотра; их фильтрует карточка объекта.
- Пантеон: изменение порядка божеств, ориентации и положения иллюстрации.
- Добавлено «✦ Создать» → конструктор витрин с коллекциями существующих объектов, форматами 3:4, 16:9, 1:1 и изменением порядка. Пантеон доступен как исходная коллекция.
- Установлены новые графические акценты и фэнтезийный фон в ателье витрин.

## Важно
- Пантеон использует собственный старый экран, в новом конструкторе доступен как источник/шаблон; полноценный переход на единый движок всех экранов пока не выполнен.
- Для нового поля «Прочитана» статус хранится на статье в JSON мира. Пока это общая отметка, не персональная отметка разных читателей.
- Для видимости обычных связей реализовано ручное скрытие; отдельная привязка к прочитанной статье для каждой связи карты в UI пока не добавлена.
- База данных/авторизация не добавлялись. Всё хранится как и раньше в файле мира и локальном состоянии.
- Полный визуальный e2e браузерный тест недоступен в этой среде; JS проверен node --check.
