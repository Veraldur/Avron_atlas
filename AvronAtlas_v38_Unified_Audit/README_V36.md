# AvronAtlas v36 — авторский лор Ивератоса и Мастерская вопросов

## Что добавлено в Аврон

- 25 новых тематических статей из авторского описания Ивератоса, с постоянными ID `iveratos-v36-*`. Все 266 исходных объектов карты сохранены.
- Шесть новых папок основной библиотеки: Космология, История, Народы, Магия и технологии, Общество, Места.
- Связи статей друг с другом и с оригинальными объектами «Купель Мор-Шира», «Ущелье Гол'Рата» и «Аттения» там, где найдено точное соответствие по имени.
- Статьи описывают только подтверждённые автором факты, различая неизвестные подробности и готовый канон. Обсуждения D&D/TES/Dragon Age в канон не переносились.

## Новая Мастерская вопросов

1. На заставке выберите «Аврон», затем переключитесь в **Редактор**.
2. Откройте любую статью через библиотеку или единый навигатор (например, «Калнави и сноходцы»).
3. Нажмите **«✦ Мастерская вопросов»** в шапке редактора.
4. В левой части выберите шаблон: народ, план, город, гильдия, персонаж, магическая технология, регион, эпоха, статья, сцена, история, языки и др.
5. Ответьте своими словами на вопросы. Заполненные поля автоматически записываются в `world.loreWorkshop.answers`. Нажмите «Сохранить ответы», чтобы принудительно сохранить.
6. Нажмите **«Предпросмотр»**, затем **«Вписать в статью»**. При повторной записи обновляется только блок данного шаблона между маркерами `AV36-QUESTIONS`, а не ручной текст статьи.
7. Для нового народа/плана или другого предмета впишите название и нажмите **«Создать новую статью»**. Она создаётся как `draft:true` и получает ссылку с исходной статьёй, если мастерская была открыта из неё.
8. «Библиотека тропов и приёмов» задаёт новые вопросы, а не пишет содержание за автора. Можно добавить собственный вопрос и собственный троп; они хранятся в JSON текущего мира.
9. Старый **Арсенал сюжетов и генератор идей/ИИ** сохранён как отдельная кнопка в левой колонке. Чтобы он использовал только что написанное, сперва впишите ответы в статью: он строит контекст из текста статьи и связей Аврона.
10. Экспортируйте JSON текущего мира стандартной кнопкой в редакторе. Все авторские ответы, свои вопросы, тропы, шаблоны и новые статьи остаются в нём.

## Важно о мире и офлайн запуске

`examples/Avron_Migrated_v36_Iveratos_Lore.json` и отдельный JSON в этом ответе — одна и та же версия. В `src/default-world-v32.js` встроен тот же Аврон, чтобы при выборе «Аврон» на стартовом экране не загружалась устаревшая копия. При наличии старого автосохранения экспортируйте его и подтвердите замену или импортируйте JSON v36.

Открыть проект можно через `START_OFFLINE_WINDOWS.bat` (при установленном Python) либо локальным сервером. Из-за браузерной политики `file://` прямое открытие `index.html` может быть ограничено. **Windows `.exe` для v36 не собирался**: предыдущий v35 `.exe` остаётся предыдущей версией, встраивать туда новые файлы вручную без перекомпиляции нельзя.

Библиотека для самостоятельного просмотра: `LORE_WORKSHOP_LIBRARY_V36.md` и `assets/lore-workshop-templates-v36.json`.
