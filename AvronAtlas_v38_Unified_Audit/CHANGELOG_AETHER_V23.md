# AvronAtlas v23 — Art Direction

- Ten independently selectable styles added to each of the three original controls: Frame, Header, Atmosphere.
- Each choice uses the local source artwork throughout the gallery, not only a background gradient.
- Per-exhibit frame selection supports all ten artistic styles.
- Per-exhibit editable epigraph and footer description, stored by stable item ID in `showcase.exhibitCaptions`.
- Existing content, IDs and old styles retained.

Limitations: the legacy Pantheon matrix and map popup renderer have **not** been comprehensively refactored in this release. Interactive browser validation is pending.
