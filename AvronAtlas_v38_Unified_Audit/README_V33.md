# AvronAtlas v33 · Советник Летописца

## Как пользоваться

1. Откройте **Аврон** (или собственный мир) → **Редактор** → любую статью.
2. В редакторе нажмите **«✧ Советник Летописца»**.
3. Выберите задачу: событие, конфликт, квест, персонаж, противник или связи. Выберите режим творчества и глубину связей 1–3.
4. В колонке «Контекст найден» показаны только материалы текущего мира: связанный объект, географические соседи, узлы города, гильдии, артефакты, загадки, приключения, витрины, события и авторские ссылки. Если статья новая, выберите её местоположение вручную.
5. **«Предложить по связям»** — полностью локальные, детерминированные *шаблонные* идеи. Это **не нейросеть**; интернет не нужен. **«Сгенерировать с ИИ»** — реальный вызов модели через локальный шлюз в Windows EXE, если провайдер настроен.
6. **«Вставить как черновик»** добавляет предложенный текст в статью с названием источников. Ни один вариант не становится каноном автоматически.

## Подключение реального ИИ в Windows EXE

Ключи не встраиваются в код и не попадают в JSON. Веб-интерфейс общается только со встроенным шлюзом на `http://127.0.0.1:48673`. При вызове модели наружу передаётся **только** статья (не более 4500 знаков) и выбранные короткие фрагменты ближайших связей (не больше 14); полный мир, иллюстрации и другие файлы не отправляются. Передача начинается лишь после нажатия **«Сгенерировать с ИИ»**.

### Вариант A — облачная модель OpenAI (требуется интернет и отдельный API-ключ)

В PowerShell для текущего сеанса:

```powershell
$env:AVRON_OPENAI_API_KEY = Read-Host "Введите OpenAI API key (только текущая сессия)"
$env:AVRON_AI_MODEL = "gpt-5.5"
& ".\AvronAtlas_v33_Offline_Windows_x64.exe"
```

Возможны затраты по тарифам API. API-ключ не совпадает с подпиской ChatGPT. **Не сохраняйте секретный ключ в общем `.bat`, проекте или JSON.** После завершения работы можно выполнить `Remove-Item Env:AVRON_OPENAI_API_KEY`.

### Вариант B — локальная Ollama (модель работает на компьютере)

Ollama и модель нужно установить/загрузить самостоятельно **один раз**. Например: `ollama pull qwen3:8b`. В PowerShell:

```powershell
$env:AVRON_AI_PROVIDER = "ollama"
$env:AVRON_AI_MODEL = "qwen3:8b"
& ".\AvronAtlas_v33_Offline_Windows_x64.exe"
```

Ollama должна быть запущена на `http://127.0.0.1:11434`. Для этого режима после установки модели интернет не нужен. Качество и скорость зависят от оборудования.

### ZIP / запуск через обычный Python-сервер

Работают локальные подсказки. Кнопка обращения к модели будет недоступна, потому что простой HTTP-сервер не содержит защищённый AI-шлюз. Для генерации через настоящую модель используйте Windows `.exe` или добавьте соответствующий серверный шлюз при будущем переходе на React и хостинг.

## Как подбирается контекст

Связи через `contentLinks`, статьи объектов, `relations`, узлы городов, связанные подземелья, артефакты, загадки, витрины, события и упоминания по названию. Географические соседи вычисляются по расстоянию на **одной карте**, максимум четыре ближайших на каждый объект. Редактор может назначить якорь «Привязать к месту», когда статья не привязана напрямую. Автоподбор не создаёт новый объект и не редактирует авторские связи.

## Важные ограничения

В старом JSON Аврона только две статьи и нет записей в `relations`, поэтому качество контекста сильнее зависит от `contentLinks`, городских переходов, находок и совпадения названий. В новых авторах и гильдиях лучше заполнять прямые связи: тогда советы станут релевантнее. AI-ответы требуют ручной проверки; они могут придумывать факты. Режим `Строго по канону` снижает, но не исключает такие ошибки.

Полный интерактивный прогон Phaser на Windows не выполнен. Изолированный браузерный тест нового редактора и мок-тест Ollama-шлюза прошли. Реальный OpenAI-запрос не выполнялся: у сборщика не было ключа.
