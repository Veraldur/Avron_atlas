# AvronAtlas v31 · Результаты проверки

## Проверено автоматически

- `node --check` для скриптов `src/*.js`, `pantheon/*.js`: синтаксических ошибок нет.
- `python tests/test_links.py`: 266 исходных объектов, 31 демонстрационная ссылка; отсутствующих целей среди них нет.
- Все 3 обложки `adventureRooms` и 6 обложек `explorerNodes` найдены в папке `assets`.
- Встроенный Аврон (`src/default-world-v31.js`) строится из того же `examples/Avron_Migrated_v31.json`, который предлагается скачать отдельно.
- Headless Chromium через `page.set_content` с реальными JS-модулями и минимальными заглушками хоста:
  1. Выбор «Аврон» / «Новый мир» и переход `Объект → Статья → Назад` работает.
  2. Редактор Амены создаёт ссылку на существующую статью по ID и сохраняет её без правки JSON вручную.
  3. «＋ Сюжетное приключение» создаёт `kind: story`, «＋ Подземелье» — `kind: dungeon`.
  4. Новая `chronicleBooks` получает `cinematicId`, а художественная запись добавляется в `chronicles`. Кнопка открывает её редактор.

## Непроверенное, важные ограничения

- Полная страница с работающим Phaser не открылась в этом контейнере по `127.0.0.1`; поэтому **сквозной визуальный тест кликов по карте не выполнен**. Частичные DOM-тесты не доказывают работоспособность каждого старого экрана.
- История «Назад» охватывает переходы из `AvronNav`, `AvronSlots`, `AvronHub`, городской модуль, модуль приключений, витрины и новые книги, а также штатный `selectEntity()`. Часть старых прямых вызовов в модальных редакторах может не попасть в историю.
- Пантеон, оригинальная Матрица, старые экранные редакторы и свободные ссылки внутри Markdown не прошли полный регрессионный тест.
- Офлайн-режим лучше запускать через локальный сервер (`START_OFFLINE_WINDOWS.bat`) из распакованной папки. Прямой `file://` может блокировать загрузку ассетов в некоторых браузерах.
- Смена мира использует существующее браузерное хранилище. Перед переключением требуется экспорт JSON; поверх локальной копии появляется собственное предупреждение и подтверждение.
- В проекте нет ИИ, аккаунтов или серверной синхронизации.

## Рекомендованная ручная проверка

1. Запустить через Windows BAT, выбрать «Аврон»; затем открыть «Миры», выбрать «Новый мир», проверить карту и редактор.
2. Вернуться в Аврон, перейти на карте к Амене → «Площадь у ворот» → «Цитадель» или объект → «Назад». Убедиться, что кнопка возвращает к предыдущему месту.
3. В режиме Редактора открыть Амену → «Редактировать место», добавить ссылку через поиск, изменить порядок, экспортировать JSON.
4. Открыть Приключения → «＋ Сюжетное приключение»; убедиться в фильтре «Сюжетные приключения», затем создать отдельное подземелье.
5. Мастерская миров → «＋ Летопись» → «Художественный редактор летописи»; записать главу, сохранить JSON, вновь импортировать его.
