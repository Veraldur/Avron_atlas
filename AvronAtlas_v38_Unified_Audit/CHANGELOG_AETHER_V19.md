# v19 — Атмосферные паки витрин

Добавлены 10 полноценных оформлений, основанных на загруженных референсах. Редактор витрин содержит сетку выбора с миниатюрами. Значение `stylePack` сохраняется в текущей записи `showcases[]` мира. `original` оставляет 3 прежние атмосферы, обрамления и классический Пантеон без изменений. Файлы иллюстраций размещены в `assets/showcase-packs/`, не подгружаются из интернета. Изображения на витрине служат оформлением фона и шапки; исходные арты экспонатов не перезаписываются.

Встроенный JSON v19 содержит исходные данные v18 и поле `stylePack` у витрин. Проверки: `node --check`, анализ структуры JSON, ZIP CRC. Полный интерактивный браузерный тест требует отдельной проверки.
