# AvronAtlas v25 — Hall & Materials Repair

- Восстановлен прямой вход в настоящий движок Пантеона (`pantheon/pantheon.js`) для витрины формата «Старый зал»: Образы, Матрица, Летописи.
- Для новых коллекций доступен формат `legacy-hall` со вкладками Образы, Матрица и Летописи на общем экране, но матрица иных коллекций использует список связей, а не весь специальный механизм божественных культов.
- Поп-up скрывается при редактировании объектов, чтобы не перехватывать клик; предпросмотр доступен после перехода в Просмотр.
- Добавлено централизованное удаление статей, разделов, витрин и летописей с подтверждением и очисткой меню/связей на удалённые статьи.
- В JSON сохранены все исходные сущности и 19 богов, витрина Пантеона переключена на `legacy-hall`.
- Экспорт JSON выполняется через «Файлы»; локальное сохранение может не сработать при большом JSON с изображениями.

## Ограничения
- Универсальная Матрица для стран не тождественна старой сакральной Матрице.
- Не проведена полная ручная проверка всех маршрутов в браузере.
