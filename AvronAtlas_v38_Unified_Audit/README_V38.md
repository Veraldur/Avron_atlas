# AvronAtlas v38 — единые материалы, связи и архивы 1.33

## Быстрый запуск

Распакуйте **весь** ZIP и запустите `START_OFFLINE_WINDOWS.bat` (Windows, Python требуется для рекомендованного localhost-старта) либо локальную Windows-оболочку, если уже пользуетесь ей. Файл `index.html` иногда работает напрямую, но браузеры могут ограничивать некоторые функции `file:`. **Отдельный Windows .exe версии 38 в эту поставку не входит.**

При выборе **«Аврон»** загрузится актуальный встроенный JSON **912 статей / 266 объектов карты**. Если у вас уже есть изменения в старом мире, **не заменяйте** их стартовой кнопкой Аврона: откройте «Продолжить сохранённый мир», нажмите `⚙ Файлы → ↓ Добавить архивы Аврона 1.33 (без замены)` и затем `Экспорт JSON мира`. Это добавит 885 страниц Foundry без замены вашего текста, а также тестовый черновик. Повторное выполнение безопасно и не создаёт дубликатов.

## Проверка ошибки с кнопкой «Открыть статью»

В режиме Редактор откройте `✧ Атлас связей`, найдите `[ТЕСТ] Пересечение Амена — Цитадель` (техническая запись). Выберите его, затем `▤ Открыть статью`: должен открыться `[ТЕСТ] Связи Летописи: от Амены к Цитадели`. Кнопка также использует новую логику для реальных пересечений: если статья не назначена, редактор предлагает **создать связанную**, а не переводит в пустое окно.

В Finder ищите `[ТЕСТ]` либо заголовки импортированных материалов. `✧ Переходы` также ищет материалы по `kind:id`. `Летопись единого реестра` добавлена как **техническая скрытая книга**, её можно найти через Finder/реестр в режиме Редактор, а не в публичной витрине.

## Файлы

- `Avron_Migrated_v38_Unified_Archive.json` — отдельно выдаваемая резервная копия мира.
- `ARCHITECTURE_REVIEW_V38.md` — детальный список модулей/данных/рисков/целевой архитектуры.
- `QA_REPORT_V38.md` — воспроизводимые проверки и ограничения.
- `reports/IMPORT_AUDIT_V38.json` — подсчёты и результаты импорта.
- `reports/UNRESOLVED_FOUNDRY_LINKS_V38.json` — все 11 отсутствующих и одна неоднозначная wiki-ссылка.
- `tools/import_foundry_v38.py` — повторяемый скрипт импорта с размещением исходных ZIP по исходным путям.
- `tools/test_browser_v38.py` — DOM/навигационные тесты (требуется Playwright).
- `assets/import-v38/` — 174 перенесённые иллюстрации.

### Нюансы

- Заголовок не уникален, поэтому Finder может предложить несколько вариантов. Это не ошибка: автоматическое склеивание разных статей запрещено.
- Исходные Markdown и изображения содержат материалы пользователя, их права и применимость в публичном проекте следует проверять отдельно.
- Только JSON **не** содержит бинарные иллюстрации: для переноса с картинками требуется также папка `assets/import-v38` из полного ZIP.
- Ревизия затрагивает основные ветви, но не доказала отсутствие ошибок во всех старых UI-кнопках, редакторах сцен и Phaser. Смотри таблицу рисков в отчёте.
