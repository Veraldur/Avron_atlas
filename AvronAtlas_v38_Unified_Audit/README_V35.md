# AvronAtlas v35 — как пользоваться большим Арсеналом сюжетов

1. На первом экране выберите **Аврон** или **Новый мир**, перейдите в режим **Редактор**.
2. Откройте нужную статью и нажмите **Советник Летописца**.
3. Выберите направление, атмосферу и свободу творчества. Дополнительно задайте масштаб, ведущий интерес, размер конструкции и долю странной магии.
4. Выберите **48 вариантов** и нажмите **Набросать**; **Ещё 48** продолжит выдачу, максимум 360 на одну сессию. Для удобства карточки разбиты по 16 на страницу.
5. Закрепляйте интересное ☆, перегоняйте отдельные идеи ↻, скачивайте подборку в Markdown, при необходимости вставляйте отдельную гипотезу в черновик статьи.
6. Нажмите **Открыть библиотеку**. Выберите одну из **28 таблиц**, найдите подходящий сюжетный мотив. Внизу можно добавить свой вариант (длина от восьми символов).
7. Авторские варианты сохраняются в `world.storyForgeTables` — экспортируйте JSON мира, чтобы сохранить их и перенести в другую копию. Базовые 568 строк остаются в файле движка.
8. Для генерации настоящей моделью нужен Windows `.exe` с настроенным `AVRON_AI_PROVIDER=ollama` и `AVRON_OLLAMA_MODEL=...`, либо `AVRON_OPENAI_API_KEY=...` с облачным API. Без модели все офлайн-функции работают самостоятельно.

**Важно:** Советник не знает истинность всех фактов; он показывает используемые ID ближайших материалов и предлагает **не-каноничные** варианты. В режиме просмотра он недоступен.

**Офлайн-сборка EXE:** отдельное окно Microsoft Edge/Chrome, встроенный HTTP-сервер доступен только локально. При необходимости заархивируйте готовую программу с JSON. Запуск Windows программы на компьютере пользователя здесь не проверялся.
