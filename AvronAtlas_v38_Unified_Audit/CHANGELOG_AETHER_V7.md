# AvronAtlas VII — единое меню и сохранение витрин

- Убрана видимая конкурирующая навигация: старые кнопки сохранены в DOM для переходов и обработчиков, но пользователю показывается одно верхнее меню «Разделы».
- Все главные разделы доступны из выпадающего списка, порядок настраивается стрелками и хранится в localStorage.
- Боковая системная панель отключена: не перекрывает редактор.
- Системные действия импорта, экспорта, создания витрины и переключения фона доступны из одного меню.
- Добавлена отдельная кнопка сохранения витрины в локальный снимок мира и оставлен экспорт JSON всего мира.
- Новые объекты появляются в витринах даже после ручного изменения порядка карточек.
- Фоновые темы карты сделаны контрастнее; непрозрачность canvas принудительно выставлена на 100%.

## Ограничения
- Надёжная долговременная сохранность обеспечивается экспортом JSON; локальный снимок может не поместиться в хранилище при больших изображениях.
- Кастомизация нижнего дока и замена отдельного Пантеона единым движком не завершены.
- Браузерные сценарии необходимо перепроверить на целевой машине.
