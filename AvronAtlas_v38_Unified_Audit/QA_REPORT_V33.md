# QA v33

## Подтверждено
- `node --check`: новые/изменённые скрипты проходят синтаксическую проверку.
- Изолированный Chromium: редактор статьи открывает советника; статья «Утраченное обещание камнерезов» получает 18 релевантных контекстных записей в радиусе 3 (загадка, артефакты, мастерская, городские узлы и другие).
- Кнопка офлайн-совета создаёт два черновых варианта без HTTP-вызова модели.
- Нажатие «Вставить» изменяет только содержимое открытой статьи; контекст на другой статье сбрасывается.
- Ручная привязка нового материала к объекту «Амена» возвращает записи вокруг города.
- Go `go test`: шлюз отключён без провайдера, отклоняет чужой Origin, вызов мок-Ollama успешно возвращает ответ с контекстом.
- Проверка целостности ZIP и встроенных файлов.

## Не проверено
- Полный обход всех кнопок с настоящим Phaser в браузере (локальная навигация браузером здесь блокируется).
- Вызов OpenAI на реальном ключе; требуется тест на устройстве с сетью и разрешённым доступом к API.
- Запуск Windows `.exe` на реальном Windows ПК.

## Примечание
- Офлайн-генератор не является ИИ. Он использует шаблоны и ближайшие связи текущего JSON.
- UI не хранит ключ в браузере/JSON. Вызовы ИИ делаются только через localhost Go-шлюз.
