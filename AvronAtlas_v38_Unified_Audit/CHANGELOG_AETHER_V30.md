# AvronAtlas v30 — Navigation Core

- Экспорт общего объекта `S` в `window.S` для добавочных модулей: исправление отсутствующего состояния у городских и других скриптов.
- Встроенный мигрированный мир v30 на первом запуске (если локальное сохранение отсутствует), без загрузки JSON вручную.
- Витрина `Амена · Город-путеводитель` теперь в `showcases` и навигации мира.
- Формат `city` в редакторе витрины, привязка к `explorerNodes`, отдельный предпросмотр формата, работающий при переключении без потери доступа к редактору.
- Слой типизированной навигации `AvronNav`, поиск, история посещений и голубые маркеры нового.
- Из выбранного объекта — перейти, связать или создать отдельную статью, витрину, комнату приключения, зону исследования.
- Кнопка «Открыть материал» на карточке витрины, работает также в Просмотре.
- Диагностика ID-ссылок внутри приложения и CLI-проверка `tests/test_links.py`.
- Все 266 объектов исходного JSON сохранены. Движки остаются независимыми; это исправление интеграции, не перенос всех движков в один.

- Добавлено диалоговое создание витрины с выбором «Галерея / Зал / Комната / Город», типа источника, существующей комнаты или городского узла.
- При удалении материалов из Консоли чистятся `contentLinks` и связанные ссылки путеводителя.
- Удалён устаревший параметр `sanitize:true` у Marked; существующая очистка HTML-предпросмотра сохранена.
- Подготовлен `QA_REPORT_V30.md` с точным объёмом автоматических и браузерных проверок.
