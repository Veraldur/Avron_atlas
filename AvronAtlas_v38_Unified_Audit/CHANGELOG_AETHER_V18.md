# AvronAtlas v18 — Chronicle Bridge

- Классический Пантеон в JSON остаётся витриной из `sections[].entries`, без дублирования богов. Добавлено редактирование самого экспоната (имя, Markdown, изображение) прямо из витрины.
- Единый редактор Летописи и датированных событий: привязка и отвязка событий, даты из `chronology.date` и совместимость с полем `f-date`, ссылки на статьи.
- Различные представления истории `chronicle`/`timeline` сохраняются в книге.
- JSON v18 сохраняет исходный мир, дополняя существующее событие датой в `chronology.date`.

Ограничения: сценарное движение камеры и полное воспроизведение старого Пантеона внутри нового движка остаются незавершёнными. Полная браузерная регрессия не проведена.
