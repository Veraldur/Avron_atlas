# Установка небольшого патча v36

**Только для распакованного проекта v35.** Распакуйте содержимое архива-патча поверх папки исходников AvronAtlas v35 с заменой совпадающих файлов, затем запускайте проект через `START_OFFLINE_WINDOWS.bat` или локальный сервер. Патч **не обновляет** монолитный Windows `.exe` v35; тот содержит собственную встроенную копию приложения.

Если старый Аврон уже сохранён в браузере, перед сменой экспортируйте его JSON, затем импортируйте `examples/Avron_Migrated_v36_Iveratos_Lore.json` из патча. При выборе нового Аврона без локального сохранения используется новая встроенная версия.

В архивах присутствуют исходные статьи, шаблоны, UI, стили и данные. Дополнительная инструкция: `README_V36.md`.
