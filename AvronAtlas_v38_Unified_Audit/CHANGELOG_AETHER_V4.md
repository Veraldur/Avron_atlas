# AvronAtlas — Aether Studio IV: Atelier of Worlds

## Добавлено
- Конструктор витрин: 3 композиции — галерея, алтарь с выделенным первым экспонатом, летопись с горизонтальными карточками.
- Настраиваемые рамы: готические арки, золотая филигрань, минимальное оформление.
- Три цветовые атмосферы: звёздный эфир, рассветное золото, багровое затмение.
- Кадрирование изображения каждого экспоната: положение по X/Y в процентах (кнопка ⊞).
- Поиск по названию экспонатов внутри витрины.
- Кнопка «Галерея стран» теперь выбирает существующий тип «Страна»/«Государство»/«Королевство» из мира, если он есть.
- Дополнительные декоративные элементы: резные золотые рамки, гербовые символы, угловые орнаменты, мягкое свечение, новые состояния наведения.
- Адаптивные стили и учёт системной настройки уменьшения анимации.

## Принципы хранения
Все новые настройки добавляются в объект showcase; объекты/статьи остаются едиными, не дублируются. Существующие витрины используют значения по умолчанию. База данных не изменяется.

## Ограничения
Это не полная миграция Пантеона на движок витрин. Персональный прогресс знания, полноценный визуальный drag-and-drop редактор и браузерное e2e-тестирование пока не завершены. Порядок редактируется стрелками. Для загрузки арта остаётся лимит 7 МБ на файл из предыдущей версии.
