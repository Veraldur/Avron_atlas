# Avron Atlas — Adventure HUD / Карта как главное окно

## Что добавлено
- Плавающий адаптивный интерфейс прямо поверх Phaser-карты: пять кнопок «Время», «Боги», «Сказания», «Знания», «Вся шкала».
- Компактная панель времени: выбор кампании и линии, шаг по годам, годовые маркеры событий, прокручиваемые карточки, запуск сцены события.
- Сворачивание до узкой шапки. Не блокирует карту целиком; верхние интерфейсные элементы сохранены.
- Перенос событий мышью в другой год на панели (только редакторский режим), подсветка будущей ячейки. Сохранение в world.timeline.events при экспорте JSON.
- Перенос по годовым ячейкам и на полном экране «Хронология» теперь работает через Pointer Events, а не native HTML Drag and Drop.
- Обновление виджетов при загрузке другого мира, смене режима и редактировании хронологии.

## Проверка
Синтаксис JS проверен командой `node --check`. Для проверки реального интерактивного браузерного запуска среда блокирует локальные HTTP и file URL; исходный проект нужно открыть локально.

## Как посмотреть
1. Запустите сервер проекта: `python -m http.server 8000`, откройте `http://localhost:8000`.
2. Для гарантированного наличия тестовой кампании при необходимости выберите «Демо-мир» (не используйте эту кнопку на несохранённом собственном мире!).
3. Внизу карты откройте «Время», переключайте годы и линии.
4. Для переноса включите «Редактор»: зажмите карточку события, потяните к нужному году на шкале и отпустите.
5. В «Вся шкала» откроется полный редактор хронологии. В «Просмотр» доступно чтение без авторских элементов.

## Ограничения
- Перетаскивание меняет только год события, пока не дату и месяц.
- Альтернативные карты и наследование состояний мира по времени ещё не реализованы.
- Интерфейс хронологии предназначен для редактирования основного JSON мира; не является облачной синхронизацией.
