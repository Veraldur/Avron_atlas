# Аврон — Мировая хронология, матрица и Finder

Версия: обновление после **Avron Atlas — Adventure HUD Update**.

## Как сразу попробовать

1. Запустите из папки проекта локальный сервер: `python -m http.server 8000`. Откройте `http://localhost:8000`.
2. **Перед экспериментом сохраните текущий мир в JSON**. Кнопка «Демо-мир» заменяет текущий мир. В отличие от неё, файл `examples/avron-timeline-matrix-demo.json` можно импортировать отдельно как демонстрационный мир.
3. **Редактор → Хронология**: кампания «Северный раскол», событие «Убийцы Королев» (748 Н.Р.). На «Дорогах времени» зажмите карточку и перетащите её на другой год. Ветка «Красный Договор» может иметь *собственную* дату, не изменяющую дату основной версии.
4. **Карта → нижний виджет Время**: событие тоже перетаскивается на год, и изменение видно на полной шкале. В «Просмотре» перенос отключён.
5. **Хронология → редактор события → Композиция события**: настройте режим `Карта + арт · разделитель`, положение шва, дымку, контраст, цвета и градиент. Параметры могут переопределяться внутри альтернативной ветви. «Открыть сценой» показывает статью без посимвольной печати.
6. **Пантеон → Матрица**: выберите Аксаара и Каллейдоиллюмиллона. Для проверки в демонстрационном мире есть **«Буря и Призма · пример»** — это *явно неканоническая* тестовая запись. В редакторе можно создавать свои записи пересечений, типы (культ, фракция, страна…), связывать статьи и объекты карты.
7. **Энциклопедия → Finder** или Ctrl+K: поиск **никогда** не создаёт статью. Кнопка «＋ Создать статью» создаёт только по явному подтверждению и проверяет дубликаты. В статье справа выделите слово в поле Markdown → **Finder — искать выделенное** или откройте контекстное меню. В Finder можно явно вставить `[[Ссылка]]` в выбранный текст.
8. **Автоссылки**: в Энциклопедии доступен переключатель. Названия существующих статей и объектов связываются *лишь в отрендеренном предпросмотре*. Исходный Markdown не переписывается. Вики-ссылка `[[Золотая Цитадель]]` открывает подходящий объект, а в Finder можно отдельно создать связанную статью.

## Что исправлено

- Выровнены шкала годов и дорожки: одна сетка с одинаковой шириной колонок.
- Перетаскивание использует координаты мыши / указателя и геометрию ячеек, не сломанный `elementFromPoint()` при pointer capture.
- Виджет на карте и полноценный редактор вызывают **единый API `AvronTimeline.moveEvent()`**. Ветки имеют свои `routeDefaults[].year`; исходная версия не обязана менять дату вместе с альтернативной.
- Год не сбрасывается из-за конкурирующих отдельных мини-шкал.
- В хронологии работают две статьи для разных версий события и самостоятельные визуальные композиции с разделителем.
- Матрица хранит записи в `world.beliefMatrix` (массив записей с `godIds`, `entityIds`, `articleId`, типом и аннотацией), учитывает черновики/публикацию, позволяет создавать статьи. Она не создаёт искусственные постоянные `pantheonIds` на объектах при сохранении пересечения.
- Finder предотвращает размножение статей, отличает поиск от создания, поддерживает прямые ссылки `[[id:...]]`, контекстное меню и явную вставку ссылки в Markdown.
- Автоматическая индексация заголовков использует ограниченный по длине поиск словосочетаний, без медленного регулярного выражения, приводившего к зависанию на длинных абзацах.
- Энциклопедия выводит библиотеки и папки как раскрывающиеся разделы, статьи добавляет порциями по 80. Поиск ищет и вложенные папки.
- День события ограничен реальной длиной выбранного месяца. Ссылки на статьи лун сохраняются при переименовании отображаемого имени луны.
- Режим чтения не открывает черновые статьи и непубличные записи матрицы через Finder.

## Как хранятся данные

Все данные остаются в JSON мира. В частности:

- `world.timeline.events[].year`, `monthId`, `day`, `focus`, `visual`;
- `world.timeline.events[].routeDefaults[]` — изменения ветви: `year`, `articleId`, `art`, `focus`, `visual`;
- `world.beliefMatrix[]` — сохранённые пересечения богов, статей, стран и иных объектов;
- `world.autoWikiLinks` — настройка автоссылок только для предпросмотра.

## Известные границы этой версии

- Мир ещё **не хранит по годам полноценные политические изменения карты**: временные ветви пока переключают сценарии, даты, статьи и визуал события, а не геометрию всех стран.
- Индексатор работает по названиям, не распознаёт падежи и контекстные омонимы без явно написанной `[[вики-ссылки]]`.
- Синематик хронологии и летописи имеют общую визуальную модель слоёв, но пока остаются двумя отдельными проигрывателями.
- Само приложение по-прежнему запускается через браузер с Phaser; тестирование на всех разрешениях и в Windows EXE отдельно не проводилось.
- Сохранение в браузер ограничено размером его локального хранилища. При больших загружаемых изображениях регулярно делайте экспорт JSON.

## Проверка

Проверены синтаксис JS и содержимое архива. В изолированном тесте Chromium (без реального рендера Phaser) выполнены переходы между хронологией, матрицей, Finder и читательской сценой. Перетаскивание по указателю прошло на полной шкале и на мини-виджете, запись альтернативной даты не изменила основной год, параметры композиции попали в объект мира. Создание одного и того же названия статьи дважды не создаёт дубликат. Автоссылки можно отключить, не изменяя Markdown.
