# AvronAtlas v10 — Pantheon Bridge

- Пантеон и витрины используют единый источник божеств (`S.world.pantheon`), без создания копий.
- В витрине Пантеона есть создание божества и переход непосредственно к его редактору.
- Новые боги обновляют экспонаты витрины автоматически после возвращения к ней.
- Для шаблона Пантеона установлена композиция «Алтарь» и готическое обрамление.
- Кнопка сохранения теперь честно показывает ошибку записи в локальное хранилище.
- Отдельная кнопка экспорта скачивает полный JSON мира, не полагаясь на обработчик другой кнопки.
- Создание шаблона и сохранение скрыты в режиме Просмотра.

## Ограничения

Это интеграция данных и переходов, а не полная миграция старого визуального движка Пантеона. Для самостоятельного сохранения между браузерами необходим экспорт/импорт JSON. Полная проверка UI в браузере не проведена.
