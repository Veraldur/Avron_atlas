# AvronAtlas v37 — Реестр материалов и отдельные черновики

- Создать статью в Хранилище → выбрать несколько родительских материалов (карты, объекты, витрины, комнаты, узлы города, боги, книги, статьи).
- Каждая связь отражается в `article.parentRefs` и в `world.contentLinks`, без копирования материала.
- Редактор статьи: кнопка «Черновики» для независимых заметок и генеративных вариантов. Нажатие «Перенести в статью» — отдельное подтверждение.
- Мастерская вопросов не изменяет статью при заполнении; кнопка отправляет результат в рабочие черновики.
- Сохранение: локальная IndexedDB (с резервным восстановлением из старого localStorage). Кнопка «Сохранить» показывает фактический результат записи. Для переноса используйте «Сохранить JSON».
- Известные ограничения: старые узкоспециализированные кнопки создания могут обходить новый диалог; это миграционный этап, не окончательное удаление старых систем. Windows EXE здесь не собран.
