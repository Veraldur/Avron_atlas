# Avron Atlas — Creative Studio v2 / Unified Lore / Chronicle Timeline

## Что изменено

### 1. Точная монтажная область

- Редактор показывает **всё исходное изображение** в естественных пропорциях (без `object-fit: cover` или растяжения в 16:9).
- Рамка выбирает **реальные нормализованные координаты области исходника**. Можно нарисовать рамку на пустом месте, двигать её, менять размер за углы и использовать колесо мыши для изменения масштаба. Углы сохраняют соотношение кадра 16:9.
- Снизу находится точный предпросмотр финального кадра; его создаёт `AvronFrame`, тот же механизм, что используется в полноэкранном просмотре события и летописи.
- «Вся карта» сохраняет целое изображение без искажений; если оно не 16:9, видны поля по краям.
- Вкладка «Арт» содержит независимый фрагмент второго изображения.
- Переходы: наезд, панорама, отдаление, проявление, статичный кадр. Время 2–16 секунд.
- В событии хронологии: **Хронология → Событие → Редактор → Открыть монтажную область**.
- В летописи: **Редактор летописей → Выбрать сцену → Открыть точную монтажную область**.
- `crop` и `artCrop` сохраняются в JSON события или летописи. Для старых сцен без `crop` оставлен прежний путь воспроизведения, пока автор не настроит кадр.

### 2. Общая матрица

- Данные пересечений хранятся в `world.loreMatrix.records`, а старые `world.beliefMatrix` импортируются один раз. Поле `beliefMatrix` сохраняется как совместимый с предыдущими версиями снимок пересечений, содержащих богов.
- Матрица Пантеона и общий Атлас связей работают с **одними и теми же записями**.
- Выбор богов передаётся между интерфейсами; из Пантеона есть переход к общему Атласу, из Атласа — обратно.
- Категории: Боги, Страны, Храмы, Ритуалы, Артефакты, Существа, Расы, Культы, Фракции, Города, События, Персонажи, Места, Статьи; можно создавать собственные.
- В режиме «Всё» выводятся группы категорий, внутри которых элементы сортируются по имени. Первоначально отображается 36 элементов с кнопкой «Показать ещё». Есть сквозной поиск.
- Новый элемент добавляется **только в выбранную категорию**, а не в начало списка. Правый клик на собственном элементе позволяет его переименовать.
- Запись пересечения поддерживает статью, описание, тип связи и замену состава выбранными элементами.

### 3. Летописи и годы

- `scene.timelineRef` хранит связь с событием и веткой; дата **вычисляется** из события, не дублируется. При изменении года события изменяется и дата связанной летописи.
- Для самостоятельной летописи можно указать кампанию, год, месяц и день.
- В редакторе летописей появился блок «Хронология / Привязка летописи».
- В библиотеке летописей есть фильтр по годам и кнопка перехода к событию.
- На экране события есть связанные летописи и кнопка «Создать летопись»; она создаёт сцену с уже заполненной связью.
- На карте в виджете времени показываются летописи выбранного года.
- В демонстрационном мире появляется пробная летопись «Убийцы Королев», связанная с событием 748 Н.Р. Тексты этой сцены — **демонстрационные, не утверждённый канон**.

## Проверка

Проверены `node --check` всех изменённых JS, а также отдельные функциональные тесты `AvronFrame` (точное преобразование координат изображения), миграции и синхронизации записей матрицы, удаления записей, и вычисления даты летописи по альтернативной ветви. Демонстрационный мир проходит `sanitize`.

**Ограничение:** в текущем окружении Chromium блокирует открытие даже локального `file://` и `127.0.0.1`, поэтому полный браузерный E2E-тест не выполнен. Рекомендуется открыть проект на Windows в Chrome/Edge через локальный HTTP-сервер и проверить интерактивные действия мышью. Запуск: `python -m http.server 8000`, затем `http://localhost:8000/`.

## Известные ограничения

- Новая система точного кадра работает в сценах, сохранённых через новый монтажный холст. Старые сцены летописей без `crop` воспроизводятся прежним способом до редактирования.
- Перенос изображения в JSON как data URL увеличивает размер сохранения; большие изображения лучше подключать относительными путями внутри проекта.
- Матрица хранит явные связи и не делает автоматических логических выводов из текста статей.
- Календарные соответствия между разными системами летоисчисления и изменение географии мира по годам ещё не реализованы.
