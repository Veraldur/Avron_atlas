# QA v36 — что проверено

- Проверен синтаксис новых/изменённых скриптов Node.js (`node --check`).
- В импортируемом JSON сохранены 266 исходных объектов, прежние приключения, Пантеон и существующие разделы.
- Добавлено 25 новых статей; выполнена проверка ссылок `contentLinks` на существование целей.
- Проверено сохранение библиотеки 17 шаблонов, 176 базовых вопросов и 20 тропов в JSON мира.
- В изолированном Chromium прошли тесты: открытие мастерской из редактора, выбор другого шаблона, ввод ответов, запись в статью, повторная запись без дублирования, создание новой статьи, перенос ответов, добавление авторского вопроса, преобразование `[[Wiki Link]]` в ссылку по ID. В этом тесте было минимальное состояние мира, без Phaser.
- Сделан снимок реального UI мастерской в Chromium; доступен отдельно.
- Попытка открыть полное приложение с Phaser по `http://127.0.0.1` была заблокирована политикой среды: `ERR_BLOCKED_BY_ADMINISTRATOR`. Сквозной тест карты, витрин и всех кнопок **не проведён**.
- Новые лоровые статьи основаны на авторских заметках; неописанные детали народов, ритуалов, организаций и технологий намеренно не придуманы как факты.
